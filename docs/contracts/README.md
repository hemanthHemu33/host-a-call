# Retired Connecto contract artifacts

`openapi-v1.json`, `openapi-v1.baseline.json`, `contract-manifest.json`, and
`v1-client.ts` document the abandoned root PostgreSQL `/v1` service. They are
kept only as migration history and are not valid inputs for runtime clients,
code generation, or API review.

The canonical API is Samvad: see [API source of truth](../api-source-of-truth.md)
and the running Swagger UI at `/api/docs`.
