# Screen Inventory

Date: 2026-07-16

Source of truth: `Voice-First Paid Calling App.pdf`.

Status values:

- `Implemented`: route exists with an interactive mock screen or shared route implementation.
- `Stub route`: a matching empty route file exists.
- `Shared stub route`: a shared call route exists, but the role-specific screen is not implemented.
- `Missing`: no route exists.
- `Not applicable`: layout/modal/sheet should be implemented inside a parent route or navigator, not necessarily as a standalone route.
