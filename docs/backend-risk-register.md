## Migration Tasks

1. Run real sandbox smoke tests for Razorpay, payout callbacks, storage
   callbacks, Agora callbacks, moderation, tagging, and FCM receipts once
   accounts/secrets exist.
2. Move remaining frontend mock-only modes behind explicit non-production flags
   once staging API credentials are available.
3. Consolidate customer host-applicant and host-onboarding paths into one host
   application workflow.
4. Add explicit host application intent instead of gender-derived conversion.
5. Feed persisted match tags, intro media, and daily host status into ranking;
   persist permissions, location, and push-token lifecycle events where still
   mocked.
6. Add redacted admin detail endpoints and field-level authorization tests before
   enabling production admin access.
7. Route feature flag and secret-ref changes through audited configuration
   commands instead of direct env edits.
8. Keep frontend HTTP adapters aligned to generated `/v1` route metadata,
   cursor envelopes, idempotency keys, and ETag/If-Match rules.
9. Add static/dependency checks that reject new direct domain status updates
   outside canonical command helpers.
10. Run Prompt 07 constraint probes from
    `docs/backend-query-plans-and-constraints.md` against a Docker/Postgres
    database and staging snapshot before production migration.
